# 👑 Throne Race · 4位玩家，1位赢家，0个朋友

> 四人抢座 · 墙棋大逃杀。灵感来自 B 站 UP 主 **Toaster_ok** 的视频《[4位玩家，1位赢家，0个朋友](https://www.bilibili.com/video/BV1GoY16qEJD)》。

**▶ 立即游玩：<https://breadbot86.github.io/throne-race/>**

单文件网页游戏，零依赖、零构建，手机/电脑浏览器都能玩。

## 玩法

四名玩家从棋盘四边中点出发，中央是 **👑 王座**。轮流行动，每回合二选一：

1. **移动** —— 棋子走一格（上下左右），不能穿墙、不能叠人；贴脸的棋子可以**跳**过去
2. **放墙** —— 在任意位置放一堵占 2 格边的墙，永久存在，用你的颜色

**第一个踏上中央王座的人获胜。**

规则保护：不允许放墙把任何玩家彻底堵死——谁都得起码留一条活路。
没有队友，没有谈判。**4位玩家，1位赢家，0个朋友。**

## 模式

| 模式 | 说明 |
|---|---|
| 经典 · 我打 3 个 AI | 传统回合制，你（蓝方）走一步 AI 走一步 |
| 经典 · 4 人同屏热座 | 传统回合制，4 人轮流操作 |
| **同步 · 实时乱斗** | 取消回合！你和 3 个 AI 同时行动 |
| **同步 · 4 AI 实时互坑（观战）** | 同步规则的纯观战，赢后 5 秒自动开下一局 |
| 观战 | 经典规则的 4 个 AI 互坑，自动续局 |

**同步模式规则**：每人 3 个操作点（上限 3）——走一步 / 放一堵墙各消耗 1 点；动作间隔 0.5 秒；每秒自动恢复 1 点。棋子头顶的白色气泡就是当前操作点，**攒点中的 AI 气泡会变金色**——它在蓄力，攒满后 0.5 秒一连发地爆发 2~4 手，小心！

侧栏还可调：**地图尺寸**（9×9 / 11×11 / 13×13 / 15×15，出生点到王座始终等距）、**每人墙数**（5~20）、AI 节奏（正常/极速）、音效。

## 本地运行

无需安装任何东西：

```bash
git clone https://github.com/breadbot86/throne-race.git
open throne-race/index.html   # 或直接双击
```

URL 参数（调试/复现用）：`?seed=123`（固定随机种子，跳过规则弹窗）、`?mode=syncspec`（pve/hotseat/sync/syncspec/spectate）、`?size=15`、`?walls=20`、`?fast=1`。

## 技术

纯原生 HTML + Canvas + WebAudio，一个文件约 30KB：
11×11 棋盘、墙合法性校验（重叠/交叉/留路 BFS）、带启发式评估的 AI（BFS 最短路径 + 放墙收益评估）、粒子彩带与合成音效。
